## أهم 5 قواعد
1. نفس الشخصية في كل فيديو، والشكل ثابت.
2. أول 5 ثواني فيها حركة، من غير مقدمات.
3. Shorts كتير، وفيديو تجميعي طويل كل شهر.
4. راجع كل فيديو بنفسك قبل النشر.
5. بص على الأرقام كل أسبوع وغيّر على أساسها.
